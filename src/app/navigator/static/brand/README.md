# Canton Bern visual assets

Reference supplied by the project owner: https://www.be.ch/de/start.html.
Retrieved on 18 October 2026.

- `logo-be.svg`: https://www.be.ch/content/dam/global/bilder/logo-be.svg
- `favicon.ico`: https://www.be.ch/static/favicon.ico
- `favicon-32x32.png`: https://www.be.ch/static/favicon-32x32.png
- `roboto-{300,400,500}.ttf`: decoded without modification from the embedded
  font data in https://www.be.ch/static/fonts.css. `fonts.css` references these
  local files and uses the same family and weights.
- `canton.css`: application styling based on the reference's Roboto typography,
  red `#DC0018`, black/white, beige `#FAF1E3`, hover beige `#F2E0C3`, footer
  `#FCF8F3`, and restrained rectangular controls.

All assets are served locally; no font CDN, analytics or third-party scripts
from the reference site are included. Asset rights remain with their owners.

Footer links explicitly refer to the canton's contact, imprint and legal/privacy
pages. They do not assert that those pages describe this prototype's hosting or
data handling. Organization-specific project contacts and legal information can
be added once supplied. The existing project/source description is preserved.

The default palette is light. A header toggle enables a dark variant and saves
the preference in this browser. The official logo retains a white background
in dark mode; printed briefs use the light palette. The footer is compact and
workspace panels use subtle borders, shadows and red accents for contrast.
